# AI lesson ideas

If you don't have any ideas coming to your mind, try using **AI lesson ideas!**
AI lesson ideas give you some suggestions to choose from.
Each idea suggestion contains a short title plus a one-line description, rather than writing the lesson
body. Pick one and it seeds a new lesson that you can try editing or using with the other AI tools.

The suggestions are tailored to the **age range** the lesson is pitched at, which is stored on the lesson document.
